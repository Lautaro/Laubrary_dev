# P6 instrument authoring implementation handoff

## Current instrument rework (2026-10-07)

This section supersedes the historical instrument-control descriptions below. Synth controls are grouped into Oscillators, Filter, Amplifier, Pitch, Vibrato and Effects sends. Fixed envelopes use the reusable ZUI ADSR/AHDSR graph with isolated stage dragging and one Undo step per gesture. Millisecond and percentage inputs accompany the graph; the graph uses square-root time spacing. Other dials use musical units, constrained editing ranges and short decimal displays, while preserving the saved physical units and untouched legacy values.

Supported scalar controls use standard `Z.Value` right-click Static/Envelope switching. A UI adapter converts the displayed unit to the existing saved unit; preparation compiles new parameter curves into the existing per-voice multipoint modulation machinery. There are no managed callbacks or allocations in that audio path. Note-on resets each voice's own clocks. Parameter and point edits use prepared live snapshots; a structural change retains the current playback and reports Stop/Play needed.

An enabled envelope without authored points is a legacy static value. Opening it preserves the stored enabled flag and empty point list. An authored curve initially occupies one label/thumbnail row; expanding that curve reveals its timing controls. Samplers distinguish All samples from This sample, and New samples labels the default new-note action copied when a sample is added. Loop, region and slice editing shows milliseconds, converts to the nearest stored source frame, and retains the two-frame minimum loop span. Unassigned mute groups read None. Effects are selected from one searchable Add effect… picker.

Curve thumbnails are framed fields with a physical start → end value, or one value for a flat curve. Expanded graphs have readable unit limits and inset handles; untouched values above the normal editing range remain visible. `ZuiValueControl.Options.valueUnit` opts into this shared presentation without converting the underlying numbers. Filter, Blend envelope, paired Blend envelope, selected modulation-device and preset Override bodies appear only when their own switch is on. The saved enable flag is independent of view folding, and toggling preserves every other setting. Parameter-curve gestures retain one complete Undo snapshot; they do not collapse it at the first move, which would freeze Redo at an intermediate point.

The instrument arpeggio controls have been removed. Pattern `0A` with argument `37` (shorthand `A37`) plays base/+3/+7 on consecutive ticks for sampler, synth and FM. Old instrument arpeggio payloads are retained and archived, never silently executed. See the owner-facing rework report and its evidence folder in the Trackeroids host for the fresh verification results; the older measurements below describe their original phase.

Canonical source is D:/UNITY/Laubrary Dev on x/zounds-sap. The original D:/UNITY/ZTracker/ZTracker source stays read-only. This is a technical handoff for root verification, not a visual-readiness claim.

## Live behavior and regression fixes

Scalar/macro editor edits now update prepared authored defaults instead of only sending a direct command. PreserveSwap compares those authored values to retain unrelated runtime/game overrides while allowing Undo/Redo back to an original authored value to reach held voices. Publishing a changed tuning base also advances retained voice step by the authored cents delta; runtime deltas remain relative to the new base. Compatible sample gain/pan and instrument-chain scalar/modifier/binding values normalize in the prepared live identity. Source topology, PCM, zone topology, unsupported curve structure and incompatible changes visibly report `Pending: Stop/Play`; authoring never secretly restarts transport.

The source metadata normalization added in mixer work dereferenced an intentionally null source-parameter list in the existing P5 malformed-neighbor fixture. Identity normalization now tolerates nullable unsupported source/automation/chain payloads in its detached copy; their original payload and existing diagnostics remain authoritative. Root must rerun the whole P5 fixture group.

Save writes the song, every distinct dirty linked instrument and the selected instrument through scoped SaveAssetIfDirty calls. There is no broad SaveAssets, original-editor refresh, Test Runner invocation, push or user-asset fixture mutation.
