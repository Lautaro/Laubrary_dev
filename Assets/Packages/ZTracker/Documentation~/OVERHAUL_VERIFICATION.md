## Paste Insert (2026-10-13, T-0594)

Paste Insert sits beside Paste in the Pattern tool column (rows-plus icon) and on Ctrl+Shift+V, next to Ctrl+C / Ctrl+X / Ctrl+V. It works on the columns the clipboard lands on: from the cursor row down, those columns move down by the clipboard's height, rows pushed past the end are dropped and counted, then the clipboard is pasted into the gap; one Undo step. Moved values are read from a copy taken before any write, because a command's identifier and its value are two fields over one cell (the first implementation lost the moved values exactly there, caught by the check). Automation lanes belong to a track rather than a column, so a track's automation points move with it only when the paste covers every visible column of that track; a paste into some of a track's columns leaves its automation in place. The dropped count shows on the window's status line ("⚠ Paste Insert dropped 2 rows pushed past the pattern end."), and also counts dropped automation points and copied rows that did not fit; it clears at the next cursor move. Hidden sub-columns (for example a pan value whose column is not shown) do not move, matching what Copy and Paste already do with hidden fields.

Verified by probe: compilation clean; Pattern overhaul 12/0.
