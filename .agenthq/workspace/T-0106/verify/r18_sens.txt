== A/FT-5 sensitivity: can FT-5 fail if FC-2.4's BAKE-TIME clamp is removed? ==
   Method: bind normally, then overwrite the compiled op's veil with 2.0 (exactly what deleting the
   bake clamp would produce), and re-measure the thing FT-5 measures - the dst alpha from PaintTile.
   baked veil as shipped                = 1.0000
   half-covered sample coverage         = 0.453203
   coverageEff WITH the bake clamp      = 0.453203   (FT-5 asserts <= coverage)
   coverageEff WITHOUT the bake clamp   = 0.453203   <- if this is still <= coverage, FT-5 CANNOT FAIL
   FT-5 would report FAIL without the clamp? NO - the test is insensitive to the clause it is named for
   reason: ShaperFillResolver.PaintTile applies a SECOND Mathf.Clamp01(veil) at use, so removing
   the bake-time clamp changes nothing that FT-5 looks at.
   the audit's own sentence says 'without the clamp it would be 1.0'; with BOTH clamps removed it
   would be coverage*2 = 0.906406, not 1.0.
