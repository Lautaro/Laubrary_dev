== A/FT-9: calibrated heap instrument, so the detection floor is a measured number ==
   allocate     1 KB -> GetTotalMemory(false) delta 0
   allocate     8 KB -> delta 0
   allocate    64 KB -> delta 0
   allocate   512 KB -> delta 217088
   allocate  4096 KB -> delta 5140480
   -> whatever the smallest RELIABLY-NONZERO row is, is FT-9's true detection floor.
   FT-9 asserts 'delta <= 0 AND gen-0 collections == 0' over 40 x 16384 samples; if the floor is
   e.g. 64 KB then a loop allocating up to ~1.6 KB per call would pass FT-9 undetected.

   gen-0 collection counter, calibrated: 
     1 MB of garbage in 1000 allocations -> gen-0 collections 0
     960 bytes in 40 allocations (a 24-byte-per-call leak at FT-9's rep count) -> gen-0 collections 0 (0 means FT-9 could not see it)
