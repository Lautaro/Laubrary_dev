## Description

FUTURE WORK - NOT SCHEDULED. Do not start until the owner opens his next Pyre session. Filed 2026-10-01 from the owner's own words (kept verbatim).

(a) Prune Pyre's Shape options and modifiers.
Owner: "Pyre has too many Shape options that are useless. Attempts that didn't work. The ones we got from importing Kiln algorithms are pretty useless. 60+ params and most don't do any changes. Impossible to work with. We should scale down Pyre. Just use the ones that really work. Same with modifiers."
Plan: audit every Shape and every modifier by measurement (does each parameter visibly change the render?); the Kiln-imported forms (60+ params, most inert) are the named worst offenders; keep only what really works.

(b) Don't delete the cut stuff - fork it into "Xpyre".
Owner: "Keep a Xpyre with all the axes functions until we fix them, evolve them or come up with something better."
Plan: main Pyre becomes the curated, working set; everything removed moves, intact, into a separate preserved tool "Xpyre" so it can be fixed, evolved or revisited later.

(c) Expand the pattern-fill mechanic with the 2026-09-30 edge work.
Owner: "The pattern fill mechanic needs to be expanded. I believe in it but we need it to be able to do more. Tomorrow we should see if we can get it to use the pattern fill functions we developed today, like edge bend etc."
Plan: connect the general pattern fill (ZuiFill textures, pixel-scale noise) to Edge response / Flow (grain along the outline), so fills can be shaped by proximity to the edge instead of being two separate systems.

(d) A proper "3D ball of fire" height-map demo - try THIS exact technique.
Owner, verbatim: "We need a proper demo of height map technique tomorrow. Make shapes that blend into one by having several layers and matte mask enables. Use luminosity to map height. Make luminosity between layers blend additively. Then we can get height to map to fire heat colors. Perhaps closer to edges turns to soot where higher luminosity gives darker richer smoke? Key is to try and make it look like a 3D ball of fire. We've learned that this will need some noise to the height map. Can't be too straight."
Starting point that already works (verified 2026-10-01): several WriteMatte layers, channel 0, Combine = Add, 'Write luminance' on, radial white->black fills; a top Draw layer 'Height from channel 0' with Mass shading (soot line, ignition, bleed, dither). Known snags: default fill gradient must be Reversed for fire (high = hot); keep summed luminance below 1 or the core saturates.

Related known issue (measured 2026-10-01): Coalesce Ramp at defaults puts 71-80% of the cloud on the gradient's last colour (density+heat clamps at 1) - worth fixing alongside (d).
