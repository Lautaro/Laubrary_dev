## Description

New zero-dependency runtime module `Laubrary.Layering` (`Runtime/Layering/`, mirrors the existing
`Laubrary.PreviewKit` pattern), holding `LayerSpec`: one `sortingLayerName` for the whole composed effect, a
`baseOrder`/`step`, and an ordered `List<string> layers` resolving a name to a concrete Unity `sortingOrder` by
list index (unknown name degrades to `baseOrder`, never throws).

**Foundational** — T-0037 (Layer Stack integration in Chunks) depends on this existing first. See
`CHUNKS_OVERHAUL_DESIGN.md` §"New shared primitives" and the design-principles discussion this session for the
concrete shape.

Not in scope here: wiring it into Pyre/PyrePlus/Zoetrope's own flat-`sortingOrder` fields — that's an explicit
open question in the design doc, deliberately deferred until Chunks proves the primitive out.
