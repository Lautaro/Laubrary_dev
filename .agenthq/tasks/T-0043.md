## Description

An editor-only test harness (no window) that loads a Kiln `contract/params.json`, instantiates the named PlusForm, renders the same frame count at the same canvas size, writes lossless RGBA PNGs (debug-only, NOT a user-facing sprite-sheet feature — that is parked), dumps float planes behind a flag, and compares stage-by-stage against the contract's goldens: field (MAD after q99 norm, Pearson, histogram EMD), silhouette (IoU + lit-area curve), exposure (t_mean/top_share curves), ramp probes (dE Lab + alpha at 11 t), pixel (MAD, alpha levels), temporal curves, plus an interleaved contact sheet. Never compares through the GIF exporter. Report §7.2, Appendix D §C.
