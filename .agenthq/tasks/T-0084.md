**Technical details:**
File: D:\UNITY\Laubrary Dev\Assets\Packages\Laubrary\Editor\Zoetrope\ZoetropeWindows.cs. ZoeWindow is the one Zoetrope window big enough to want the bar; WeaponDefWindow/AmmoDefWindow (same file, share the ZoetropeDefWindow<T> base) were left untouched — the user's request named only the Zoe editor.

Root obstacle: ZoetropeDefWindow<T>.BuildAsset was `protected sealed override`, so ZoeWindow (which only had a BuildBody override) could not add a bar host above its own ScrollView the way ChunkWindow/MirageWindow do. Fix: dropped `sealed` from the base's BuildAsset (kept `override`; a first edit accidentally dropped `override` too and broke the whole abstract-member chain for all 3 subclasses — CS0534/CS0533 — caught by recompile_status and corrected). Also widened access on 3 base fields/property so a subclass can reuse the exact scroll-offset-preservation dance: `So` setter private→plain (inherits the property's protected access), `_scrollOffset`/`_restoringScroll`/`_scroll` private→protected.

ZoeWindow now overrides BuildAsset directly (previously only had BuildBody, which is now unused for this class — the per-section logic that used to live inline in BuildBody was split into BuildIdentity/BuildStats/BuildLook/BuildRigUnit/BuildReactionsSection/BuildAiSection/BuildWeaponsUnit, each adding exactly one top-level ZuiSection, run through a Zoe-local Unit(body, zoe, label, build) helper — same idiom as ChunkWindow.Unit/MirageWindow.Unit). BuildRigUnit registers nothing when Zoe.view isn't CompositeLauminaryView (mirrors Chunks' Fragment Slicer no-op-when-empty precedent), so the bar only ever lists Rig for composite characters. BuildCues was already shaped as `void BuildCues(VisualElement, Zoe)` adding its own section, so it plugs into Unit() unchanged. The Loadout field stays a bare, un-barred PropertyField between AI and Weapons, same as before (a PropertyField's own foldout already carries the name, so it isn't a ZuiSection and was never addressable by the bar in the sibling tools either). ReserveBarHeight copied verbatim from ChunkWindow.
