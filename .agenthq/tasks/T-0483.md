DESIGN: per point randomX (share of the curve's length), randomY (curve values), randomBias (default 0.5), stored on the shared point type. Offset = hash(play seed, modifier, point) -> angle u1*2pi, distance R*u2^k with k = 0.5*(1-b)/b (k=1/2 at b=0.5 = even by area; b->0 centre, b->1 edge). Drawn time clamped between the midpoints to its neighbours (order can never change), first/last keep their time, drawn value clamped to the curve's range.
FORK (decided): the draw is not stored as a per-voice copy of every curve; it is a pure function of the play's seed (set at play start from the token, kept in the voice) and the point, so it is the same value every time it is read. Why: a copy would have to be reallocated and kept in step whenever a live edit swaps a playing voice's layout, which cannot allocate on the audio thread; the pure draw needs nothing and is equivalent. Curves without random points take the exact old arithmetic.
PLAY LENGTH uses the drawn curve: StartVoice measures with the play's own seed (declared = rendered per play, measured). The strip shows 'Plays ~X s' (curve as drawn) when a curve has random points, with a tooltip.
SCOPE: engine honours random points on every envelope (volume, pitch, time, and the chain's Envelope modifiers). UI Toolkit editing (right-click a point -> Random / Across / Height / Bias popup, one row, one Undo step, the pitch curve converting off the old scale first inside it) on the Klip waveform curves AND the chain card curves. IMGUI: ellipses drawn read-only (the IMGUI envelope control is someone else's file). Not done: the older DspVoice/offline renderer path (used only by checks) does not draw random points.
