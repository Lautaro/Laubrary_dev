## Description

**Owner's ask, his words:** "Step modifier: no no no, having an input box per step is silly. Basically it should be one vertical slider per step. It should look like a band or bar."

**Approach:** replace the per-step number boxes with a row of bars (like a bar graph or equaliser bands), where each step's value is set by dragging its bar's height. It must work for however many steps a Step modifier can have, and stay undoable. Check first whether ZUI already offers this control; if it does not, flag it as a ZUI gap per the project's ZUI-first rule.

### 2026-09-27T15:31:44Z — agent — in_progress -> done
Done. The Step modifier's steps are a row of bars, one per step, each set by dragging its height, like a step sequencer or an equaliser.

ZUI FIRST: ZUI already has a vertical slider, but it is a thin groove with a knob. A row of them reads as a mixing desk rather than one shape, and each is a separate control, so a sweep across the row changes only the first. So a new reusable control was added to ZUI itself, 'BandSliders': a row of bars set by dragging their height, filled from a baseline, drawn in the active ZUI sheet's own slider colours. It returns a changed copy so the caller records Undo first, like every other ZUI control. It was added to ZUI rather than painted inside the Zounds window, per the project's ZUI-first rule; any other tool with a list of values (an equaliser's bands) can use it.

BEHAVIOUR: drag a bar to set it; sweep across several to paint them in one gesture (bars the mouse skipped over are filled in along a straight line); double-click a bar to reset it to the middle. Bars run -1 to +1 about a middle line, the same scale an oscillator uses at Amount 1, so a top bar moves a bound parameter as far as an oscillator's peak would. Each bar is at most 44 points wide, so a short list is not stretched into slabs; a long list narrows to fit. The step count and the add/remove buttons sit on the header row. The maximum is 24 steps, because round-robin order can only keep track of 24; the add button says so when it is disabled. A value saved outside -1..1 by the old number boxes is shown with a bright cap and kept unchanged until that bar is dragged.

VERIFICATION:
- By eye: the real chain editor, drawn in a temporary preview window (deleted afterwards) for an in-memory sound with a six-step list. The bars read as one band, up and down from a shared middle line, in the Zounds sheet's colours.
- By probe, with real mouse events fed into the control: a sweep from the top of bar 2 to the bottom of bar 5 set them to +1.00, +0.33, -0.33, -1.00 and left the rest untouched; an out-of-range 1.60 was kept until double-clicked, which reset it to 0.
- By reading the code: drags go through the same one-undo-step-per-drag path as every other slider in this editor. Not exercised against real data, so as not to touch the owner's library.
- NOT verified: a human dragging it; the tooltips on screen.
- Noticed, not changed: the existing Step setting 'Reset on trigger' has its label clipped to 'Reset on trigge' by a fixed label width.
