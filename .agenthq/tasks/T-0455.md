## Description

Found during T-0409 by code search, not by ear. The offline stretcher (ZoundTimeStretcher.Get/Render) is only called from the editor's stretch strip, to pre-warm its cache; nothing in the runtime playback path (ZoundSapPlayback.StartVoice reads the raw PCM from ZoundPcmCache) applies it. So a Klip's Stretch (Uniform, Region, Curve) is most likely not heard when it plays through the chain, the same kind of loss in the port as the Random draw (T-0447).
