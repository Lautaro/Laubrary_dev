## Description

The user's request, verbatim intent: "Where there is a collection of bands, the UI is quite a difficult way to set each band. I suggest a bespoke UI: a slider can set the number of bands, then a gradient can be set to quantise the same number of quanta."

Mapping: a hard band table (N thresholds + N colours) IS a stepped gradient — N keys = N bands, key positions = thresholds, key colours = band colours. So the control = a count MicroSlider (resamples the table) + a stepped gradient (drag a key = move a threshold, click a key = edit its colour) + a quantised preview strip. Contract band tables convert losslessly, so presets and byte parity are preserved: the control changes presentation, never bytes.

Scope: a `PlusBands` type next to `PlusRamp`; ONE `ZuiReflect` drawer case; adoption in every form whose source is a hard band table (Torch, Arc Burst, + whatever grep finds); presets converted; contract loader kept working; parity re-dumped against the T-0063 baseline on every draw; tests; ZuiAudit + PrintWindow captures; docs.

Standing rules: autonomous, never stall, log decisions here. ### 2026-08-21T11:30:00Z — agent — design decided (without asking)
**Band users found by grep:** only two hard band tables exist — Torch `TorchSettings.ramp` (7 cel bands, stored as a 14-stop step `PlusRamp` per the contract; `rampTop` is a scalar dial, not a band set) and Arc Burst `bands` (5 cel bands, `ArcBands.*`). Orb / Plasma / Jet `ramp` fields are smooth LUTs (`BakeLut`) and stay `PlusRamp`.
**The 8-key question:** Unity's `Gradient` caps at 8 colour keys and its Fixed mode colours a band by the key at its END (the key's time is where the band stops), the opposite of Kiln's threshold-at-START rule; Torch already has 7 bands and the count slider must go past 8. So storage is NOT a Gradient: `PlusBands` keeps a plain sorted `List<PlusRampStop> stops` (pos = the threshold where the band starts, color = the band) and `Eval` is `PlusShade.Banded` over cached `Thresholds` / `Colors32` tables — the forms keep calling the same `Banded(t, thr, cols)` with the same arrays, so bytes cannot move. `ZuiGradient` wraps a Unity Gradient, so it has the same cap — not used.
**Why the list is named `stops` of `PlusRampStop`:** it is the same serialized shape as `PlusRamp`, so a layer saved with the old `PlusRamp` field loads into the new type with no migration code and no legacy field; `OnAfterDeserialize` sorts and collapses repeated positions to the later stop (exactly the old `PlusTorch.Bands` reading), so an old 14-stop Torch table becomes 7 clean bands on load.
**Below the first threshold:** `Banded` paints colour 0 there; Arc's own rule makes the pixel absent. `PlusBands.transparentBelowFirst` (set by the Arc presets, not drawn) tells `Eval` / the strip to show that region transparent so the preview is honest, and it is also what makes the first marker draggable (Torch's first threshold is 0 and locked — moving it would change nothing, so the control does not offer it).
**SetCount rule:** grow = split the WIDEST band at its midpoint, the new band copies its colour (the picture is unchanged until you recolour it); shrink = remove the NARROWEST band (never band 0), the band below absorbs its span. Existing thresholds and colours are never resampled.
**Drawer:** `IZuiBands` (ZuiRuntime, so the Zui toolkit never references PyrePlus) + ONE `ZuiReflect` case → `ZuiBandsControl`: a `Z.MicroSlider` "Bands" (1..16) beside ONE stepped strip painted from `Eval` over a checker (the editor surface IS the quantised preview — a separate preview strip would be the identical image, so it is not drawn twice); markers under the strip drag a threshold (clamped between its neighbours), a click on a band opens a `Z.Popover` with the band's colour (`Z.Color`, the sanctioned colour island) and its threshold as a MicroSlider. The control is registered as a wide control so it takes its own line in the card flow.
**Arc field rename:** `bands` → `palette` (`[FormerlySerializedAs("bands")]`) so the field label is not the same word as the slider inside it; it is also the contract's own key.
