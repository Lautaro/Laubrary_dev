## Description

Small reusable libraries the core offers to ANY form (report §5.2): (1) float-plane toolkit — separable gaussian/box blur, directional N-tap + IIR smear, bilinear domain warp, bloom, multiply-by-noise; (2) shade modes — linear-light LUT with per-stop alpha + ramp presets, banded/cel fill, dual-ramp crossfade + 2-D palette, additive emissive per-channel 1-exp tone map; (3) clip-level field-statistic normalisation (never per frame); (4) per-form supersample kx with premultiplied down-filter; (5) spec-hash-cached deterministic pre-pass; (6) pass the full swarm instance record (x,y,own,spawnLife,index,orientDeg,zNorm,sizeMul,brightMul) to whole-layer forms and make PyrePlusField's sample/accumulate/threshold/relief public. Each lands with a unit test and is exercised by at least one real port. Default/empty path stays byte-identical.
