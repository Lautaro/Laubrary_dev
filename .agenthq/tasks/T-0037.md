## Description

Wires `Laubrary.Layering.LayerSpec` (T-0032) into `ChunkSpec` as an ordered list of named, typed slots
(Fragment vs Burst — e.g. `Blast` / `Fragment1` / `Smoke` / `Fragment2` / `Fireball` / `Fragment3`), each
resolving to a real Unity `sortingOrder`. This is what turns the standalone modules (T-0033..T-0036) into one
composed, layered process — the full death-effect example in the design doc's Vision section is the target
proof case.

**Depends on T-0032** (the primitive must exist first). Includes the Layer Stack ZUI panel — drag-reorder via
`ZuiThumbGrid` (already shared between PyrePlus's CherryFraming and the Laumination Builder) — and the Envelope-
style popover context menu for adding a layer. Also where the "possibly a Sorting Layer ZUI picker control" gap
gets resolved or explicitly deferred. See `CHUNKS_OVERHAUL_DESIGN.md` §"Standalone modules" #5 and §"UI
architecture".
