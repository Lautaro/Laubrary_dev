## Description

Expand the function to add an anchor to a pyre. 1. Anchors are optional. They are used for placing. They are expected to show the start, center or base of the pyre. The UI and preview should not be on by default. Only if user chooses to set it. Let me know if you think having anchor and origin as different points makes sense or if they should be the same. Make a note that the anchor vector doesnt do anything by itself its just a way for the authot to tell the system how to treat the pyre. With this task look at Zoes weapon event (and similar). The first use case for anchor vectors is the muzzle flash of ProtogGuy. Configuring the weapons fire to point in the right direction should be quite easy when there is an anchor direction. So make sure it makes use of it.

**Details:**
Anchor vs origin: they should be ONE thing, and that is how it is built - a Pyre with no anchor keeps its implicit origin (the canvas centre); the moment you set an anchor, that point IS the origin everything pins to. There is no second point to keep in sync.

How to use this: open the Pyre in its window, Canvas section, press Anchor. Choose Position or Vector. Click the preview to place the dot; drag the dot to move it; for a Vector, drag the arrowhead to aim. Every edit is undoable. The anchor does nothing by itself - it only tells placing systems how to treat the Pyre.
