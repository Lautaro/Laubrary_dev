**Technical details:**
FIXES

1. Zui/Toolkit/Zui.cs, Z.Field. T-0287 registered a GeometryChangedEvent on the field WRAPPER and wrote wrap.style.height from evt.newRect.height. Pinning the wrapper's height stops the wrapper's own rect changing when its content changes, so the callback fires once and never again - any control that grows later (a ramp opening its Adjust box, an envelope expanding, a 2D pad unfolding) is left overhanging a frozen row. Replaced with one shared StampFieldHeight(wrap, label, control), called from a GeometryChangedEvent on BOTH the wrapper and the control; it takes max(control + its vertical margins, label + its vertical margins) plus the wrapper's padding. .zui-field is flex-direction: row (ZuiToolkit.uss:331), so max() is the right reduction. NaN-guarded on both children. Verified on Pyre's own window and on Shaper's hosted Torch and Jet cards.

2. Editor/Shaper/ShaperWindow.Lights.cs. atCap was computed once in BuildLightsSection. The + Add light button is now a field (addLightButton) refreshed by RefreshAddLightButton() from RebuildLightList(), which every add, remove, enable-toggle and reorder already routes through. Same file: the ambient strength slider is captioned "Strength" rather than "Ambient x" (the word Ambient already labels the colour swatch it shares the row with), and the Specular tooltip states the flat-normal condition it was measured to have.

3. Editor/Shaper/ShaperFilmstrip.cs + ShaperWindow.cs. _tile is no longer readonly and ShaperFilmstripElement.SetTileSize(float) restyles the strip's height and every tile in place, keeping the tiles, their textures and the pre-baker. The Tile size slider calls that instead of FillTransport(), which cleared transportHost and so detached the very slider being dragged. This is the shape PyreCherryPanel's own Tile px slider already uses: it rebuilds the grids, not the box the slider lives in.

4. Editor/Shaper/ShaperWindow.Cherry.cs. The Zound cue row is flexShrink 0 and flexWrap NoWrap. Measured cause: the slider (150 + 6.22 margin) and the picker (3.11 + 170 + 6.22) need 336.00 px and the group resolved to 335.56, so Yoga rounded that tie into a wrap - onto a second line the row reserved no height for.

5. Editor/Shaper/ShaperShapePicker.cs. The Sprite/Image entry's tooltip now says nothing is drawn until a sprite is assigned. It is the only one of the 43 entries that renders nothing at its own defaults.

No Pyre file was touched. No serialized field renamed, no default changed, no render code touched, no new menu item, no new control, no commit.
