## Description

**The good news first: the actual CherryFraming UI code mostly SURVIVED.**
`Assets/Packages/Laubrary/Editor/PyrePlus/PyrePlusWindow.CherryFraming.cs` and
`Assets/Packages/Laubrary/Runtime/PyrePlus/CherryFrame.cs` are both untracked
(`??`) files that were never committed — so the crash+restore (which only reverts
TRACKED files) didn't touch them. All the hard-won UI fixes documented in
`pyreplus-cherryframing.md` (drag-reorder via no-capture + window-level state,
right-click popover anchored to `Z.Menu(card)`, multi-drag, etc.) should still be
in that file's actual code. **Do not rewrite `PyrePlusWindow.CherryFraming.cs` or
`CherryFrame.cs` from scratch — read what's there first, it's very likely intact.**

**What's actually lost: `PyrePlusSpec.cs` itself**, which IS a tracked file and
shows no uncommitted diff right now (fully reverted to the 2026-08-05 commit). It's
missing every field CherryFraming.cs currently reaches for (confirmed via compile
error, ~40 references across the file):

- `previewBackSplash` (BackSplashSettings, lazily allocated — the per-asset
  backdrop; this is what the sixth-pass `EditorUtility.SetDirty(spec)` fix was
  protecting)
- `cherryEnabled` (bool, drives the section-header toggle)
- `cherryFrames` (`List<CherryFrame>`)
- `previewCherryStripSize`, `previewDelay`, `previewZoom`, `previewFps`,
  `previewStrip`, `previewShowFrame`
- `previewZoundFrame`, `previewZoundName` (Zound-on-loop preview integration)
- A `ResetCherryPlayback()` method (currently `CS0103: does not exist` — was
  presumably on `PyrePlusWindow.cs` or `PyrePlusSpec.cs`, check both)

Also reverted (all show clean git status = back to Aug-5 state):
- `PyrePlusWindow.cs` — lost the `CherryTick` restructure, the transport-row Delay
  slider (moved out of the cherry-list area per pass-4 feedback), the draggable
  preview resize bar (`previewHeight` field, [140,900] clamp), and the
  `backSplash` property reading from `spec.previewBackSplash` (previously a
  window-held `_backSplash` field — THAT was itself a bug fixed by this change;
  reverting brings the bug back too).
- `PyrePlusWindow.Preview.cs` — lost the `frame < 0` blank-during-delay branch and
  the `lastPreviewView` rect caching for auto-fit.
- `PyrePlus.asmdef` — lost its `com.Lautaro-Arino.Laubrary.BackSplash` reference
  (needed for `previewBackSplash`'s type) — this alone will cause a fresh compile
  error the moment `previewBackSplash` is re-added without this.

Full field-by-field spec, exact bug-fix rationale (backdrop SetDirty, auto-fit
floor-vs-exact, popover anchor math, capture-vs-no-capture drag), and the "How to
apply" notes for extending this safely are all in `pyreplus-cherryframing.md` —
read it in full before rebuilding, it is detailed enough to do this right the
first time rather than reintroducing bugs that were already fixed across 7 passes.
