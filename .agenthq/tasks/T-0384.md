## Description

**Owner request (2026-09-21).** When a Chunks recipe is handed off to "Preview in Mirage," the recipe's own configured preview backdrop should carry over so Mirage shows the burst against the same backdrop it was tuned against, instead of Mirage's own separate default.

**Already well-grounded, both sides confirmed by reading the code:**
- `ChunkWindow.Preview.cs:104-112` — `Backdrop` reads/lazily-creates `Current.previewBackSplash` (type `Laubrary.BackSplash.BackSplashSettings`), stored ON THE RECIPE (`ChunkSpec`) itself — its own comment says exactly why: "the backdrop lives on the RECIPE, so the one a burst was tuned against comes back with the burst rather than with whichever window happened to be open."
- `MirageView.cs:48-52` — `public BackSplashSettings backSplash = new BackSplashSettings();` — the SAME type, described as "a private, owned COPY of a BackSplash preset's fields (not a shared asset reference)."
- `PreviewInMirage(ChunkSpec spec)` (`ChunkWindow.Preview.cs:820-829`) currently creates the `MirageView` and never touches `view.backSplash` at all, so it's left at its own default-constructed value, ignoring whatever the recipe's own `previewBackSplash` is set to.

**Fix:** in `PreviewInMirage`, after `ScriptableObject.CreateInstance<MirageView>()`, copy `spec.previewBackSplash`'s fields into `view.backSplash` when the recipe has one set (i.e. `spec.previewBackSplash != null` — check whether `BackSplashSettings` already has a copy-constructor/Clone method or field-by-field copy is needed; `BackSplashSettings` is a plain serializable class, not a ScriptableObject, so a straightforward field copy is expected — check for an existing copy helper elsewhere in the codebase before writing a new one, this exact "clone a BackSplashSettings" need may already exist somewhere BackSplash presets are duplicated). Leave Mirage's own default behavior unchanged when the recipe has no backdrop configured (a fresh/never-touched `previewBackSplash`).

**Verify:** set a distinctive backdrop (a colour, or an image) on a Chunks recipe's own Preview backdrop panel, press "Preview in Mirage," confirm Mirage opens showing the SAME backdrop rather than its own default.

Read `D:\AgentGuide\ui-rules.md` and the laubrary skill's `references/ui-layout-rules.md` if any UI needs touching (this should be logic-only, no new UI).

Editor rights: YES for verification — check whether the owner is actively in the live editor before claiming it.
