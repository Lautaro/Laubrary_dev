**Details:**
Sprite is the first Shaper primitive with no analytic SDF, so ShaperCompiler.EmitLeafFrom forks it around ShaperPrimitives.Bake entirely (ShaperCompiler.cs:724-731) into a new EmitSpriteLeaf (ShaperCompiler.cs:778-825), which resolves the sprite/threshold/softness dials at compile time (ShaperValue.Sample, same funnel-once-per-compile rule every other dial follows) and fetches/builds a cached raster from ShaperSpritePrepassCache.Get (Runtime/Shaper/ShaperSpriteField.cs). That cache computes an exact 2D Euclidean distance transform (Felzenszwalt & Huttenlocher, two 1D lower-envelope passes, ShaperSpriteField.cs:220-274) of the sprite's alpha channel -- pre-blurred by the softness dial (box blur, ShaperSpriteField.cs:198-216), then thresholded -- and caches it keyed by a content hash of (sprite instance id, half-extents, threshold, softness, fit mode) on the owning ShaperPrimitiveDef via a ConditionalWeakTable, copying PyrePrepassCache<T>'s identity+snapshot pattern (Runtime/Pyre/PyrePrepassCache.cs) rewritten against Shaper's own types since Runtime/Shaper has no Pyre dependency. A new ShaperOpKind.SpriteSample (ShaperProgram.cs:41-49) and ShaperProgram.spriteFields array carry the raster to the evaluator, which bilinear-samples it directly (ShaperEvaluator.cs, SampleSpriteDistance) -- a REAL distance everywhere on the raster, unlike ShaperOpKind.CompositeSample's coverage-inverted pseudo-distance which only holds within about one bake texel of the edge (ShaperEvaluator.cs:222-243's own doc names this saturation). Declared bound 1f (ShaperPrimitives.cs:272-277), same 'no invented meaning' posture EmitComposite already takes. Fit mode Uniform (letterboxed, preserves sprite aspect) / Stretch (fills the box) governs how the sprite's own pixel rect maps onto its authored half-extent box (ShaperSpriteFitMode, ShaperPrimitives.cs:29-36; mapping math ShaperSpriteField.cs:130-146).
