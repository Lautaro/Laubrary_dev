### 2026-09-27T15:54:21Z — agent — in_progress -> done
Done: the owner was right, it was a real bug, and it is fixed.

MEASURED FIRST, three plays per case, reading which step each new play starts on:
- Per play, on: 0, 0, 0 (correct). Per play, off: 0, 1, 2 (correct).
- Per interval, on: 0, 0, 0 (correct). Per interval, OFF: 0, 0, 0, the same as on. This is the owner's case (his list is Per interval).
CAUSE: when a play starts, the list's position was only set if the setting was on, or if the timing was Per play. For Per interval with the setting off, nothing set it: the engine advances steps during a play but never carried that position back, so every play began at step 1.
FIX: in Per interval with Retrigger off, the list now keeps stepping on its own clock whether or not anything is playing, and a play joins it wherever it has got to. This is the same meaning the owner chose for the LFO's 'Always'. It is not 'carry on from where the last play stopped', because that would mean reading a finished voice's memory, which may already be released (the crash class fixed in T-0419). Round-robin order stays a no-repeat shuffle: each pass through the list is shuffled from the pass number, so every play agrees.
RENAMED to 'Retrigger' (stored value unchanged, so saved sounds keep their setting), with hover text explaining what on and off do in each timing. 'Start random' is hidden when the list runs on its clock, because it has no start to randomise.
VERIFIED:
- Seven later plays, at delays of 90 to 370 ms, each started on the value an earlier play had reached at that moment, 7/7, including mid-glide values.
- Round-robin shuffle across 400 passes for lists of 2, 3, 5, 8 and 24 steps: no value twice in a row, every pass complete. A 2-step list first repeated 204 times; fixed to alternate, re-measured clean.
- Kept check 9 now includes this case and passes: 5/5 plays joined the clock, 3 different starting steps seen. Before the fix every play started on step 0, which fails both tests.
- Seen by eye: 'Retrigger' in the owner's panel.
NOT verified: a built player.
