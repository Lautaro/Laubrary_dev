**Scope note, explicit from the owner:** do NOT touch the size of the recipe currently being used for the sub-pixel visual test (`Assets/Zoetrope/Floating Disc.asset`'s own Hit `DebrisScatter` capability, just hand-tuned to `sizeMin: 0.0625, sizeMax: 0.0625` — exactly one game pixel, on purpose, for an unambiguous pass/fail screenshot test). This task is about the underlying SAMPLING FUNCTION(s) that produce crops bigger than 1px, for every OTHER recipe that uses (or will use) a larger size range.
