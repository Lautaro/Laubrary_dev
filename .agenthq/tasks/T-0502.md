## Description

Found by the T-0500 research pass (D:/Claude@GDrive/Zounds Non-Destructive Editing Research 2026-09-29.md) on 2026-09-29. None was touched by the ZPOC build (T-0491), which only added the id chip to the track cards.

1. **Sizes and draws from rendered files.** The Zequence strip sizes and draws its tracks from rendered files, not from the sound as it plays now (its original audio through its chain). A track whose chain changes its length, or whose render is stale, is drawn wrong.
2. **Playhead uses elapsed time.** The strip's playhead uses elapsed time rather than where each play is reading its audio. The Klip waveform was moved to the source position in T-0493, and the same fix applies here: live speed makes elapsed time wrong, and a sound with live speed declares a long upper bound as its length.
3. **Render to Klip renders as a side effect.** Its "Render to Klip" action first renders each Klip to a file. That is the same side-effect rendering removed elsewhere (Stretch, T-0481); nothing should write a rendered file except an explicit bounce.
