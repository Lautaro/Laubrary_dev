## Description

The authoring/playback backbone: when each attached module (T-0033..T-0037) fires relative to burst-start, drawn
as a bottom-docked track view in the spirit of PyrePlus's own envelope timeline. Two event types fire along the
way:

- **Code Event** — a free-text hook name, fires an arbitrary named callback the game code can subscribe to.
- **Zound Event** — built-in, references a Zound via a picker (never a typed string, per the project's "never
  type a reference string" rule) — wiring audio to any point in the process is a drag-a-marker operation, not
  code.

This is the structural backbone the design doc calls out as the UI's spine — other module panels stack under it.
See `CHUNKS_OVERHAUL_DESIGN.md` §"Standalone modules" #6 and §"UI architecture".
