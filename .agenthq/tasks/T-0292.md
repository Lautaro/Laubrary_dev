## Description

Found by T-0288, read on screen in the live Shaper window with Cherry Framing on.

Both controls set a thumbnail size in screen pixels and nothing else:
- the transport's, under the filmstrip, is captioned **"Tile size"** -- renamed from "Tile px" by T-0257 with the reason "an abbreviation of a unit, not a name for the thing it sizes" (`Editor/Shaper/ShaperWindow.cs:1567`);
- the cherry panel's, over the source-frame grid, is still captioned **"Tile px"** (`Editor/Pyre/PyreCherryPanel.cs:243`).

They are 250 px apart in the same pane when cherry framing is on. T-0257's rename simply did not reach the shared panel, because the shared panel is Pyre's.

Not fixed under T-0288: `Editor/Pyre/PyreCherryPanel.cs` is a Pyre file, read-only for this programme, and the caption is Pyre's own chrome (`PyreCherryPanel.Chrome.tileSizeTooltip` and the literal beside it), so renaming it renames it in Pyre's window too -- which is probably right, but it is the owner's call, not an audit pass's.
