**Details:**
Editor/AssetKit/AssetLibrary.cs, Duplicate(T src): replaced `AssetDatabase.CopyAsset(path, copy)` + `AssetDatabase.LoadAssetAtPath<T>(copy)` with `var made = Object.Instantiate(src); made.name = Path.GetFileNameWithoutExtension(copy); AssetDatabase.CreateAsset(made, copy);`. LauTag side-data: read LauTagLibrary.cs -- tags are stored in a GUID-keyed side table (AssetTagEntry.guid), never a field on the tagged asset, and neither the old CopyAsset path nor Instantiate carries a GUID-keyed entry to the new asset's new GUID -- so tag data was NOT carried by Duplicate before this change and still is not; this is unchanged pre-existing behavior, not a regression. Object.Instantiate deep-copies a ScriptableObject's serialized fields including [SerializeReference] polymorphic graphs (Unity 2019.3+); it does not by itself register the new object with the AssetDatabase or give it a GUID -- that only happens at CreateAsset, same as Create() already does elsewhere in this file.
