## Description

Runbook row 0 (user-raised 2026-08-20): Wobble/Rotate/Scale/Skew/Turbulence… (the `GeometryModifier` family) did nothing on the plug-in forms (Plasma Bloom, Arc Burst, ForkBlast) — they receive `ctx.geo` and ignore it; only Inferno warps per sample. Pixel and Post modifiers already work. Fix in the core: after a form renders its isolated scratch, the renderer inverse-maps every destination pixel through the layer's geometry modifiers (same `GeoCtx`/phase/`WarpPass` conventions as the Disc path and Inferno) and resamples the source buffer; published parity planes get the identical warp. `PlusForm.HandlesGeometry` (default false) lets a form that warps internally (Inferno) opt out so it is not double-warped. Default path (no geometry modifiers) must stay byte-identical.

Master plan: `D:\Claude@GDrive\Kiln to PyrePlus\RUNBOOK.md` row 0. Standing rules: autonomous, never stall, commit after each verified milestone, log handovers here.

Decisions taken without asking:
- **Where:** one new helper `Runtime/PyrePlus/PlusFormWarp.cs` (public static, so tests can hit it directly) called from `RenderFormLayer` right after `form.Render`, before the FieldSink publish. Nothing else in the renderer changes.
- **Semantics = Inferno's per-sample convention, layer-centred:** offset = (px+0.5−W/2, py+0.5−H/2) in canvas pixels (row 0 = bottom ⇒ y-up already), `GeoCtx(W/2, H/2, centre = zero, radius = min(W,H)/2)`, modifiers applied highest `WarpPass` first (the `ModSet.geo` array is ascending, so iterate in reverse exactly like `ApplyGeo`/Inferno), `phase` = the renderer's per-frame wobble phase. Inferno uses `safeRadius·min(W,H)/2` for the radius; a generic form has no "safe radius", so the full half-extent is the default — only shape-locked warps (Profile/Sphere) read it.
- **Layer-level, not per-instance for swarms.** The Disc path warps each particle around ITS OWN centre (GeoCtx.center = particle offset, radius = particle radius); this pass warps the whole layer buffer once around the canvas centre. That is what "wobble the layer" means for a field form; a per-instance warp for swarms is a possible later refinement, NOT built now. Documented in the design doc.
- **Sampling: nearest only.** `floor(warped + centre)` — identity-equivalent warps (Scale 1, Rotate 0°) map every pixel to itself exactly, hard pixel-art edges survive like on Disc. No bilinear: no layer-level sampling choice exists today and inventing a dial is out of scope. Straight alpha, RGBA sampled together, outside ⇒ transparent (0,0,0,0).
- **Parity planes:** the FieldSink wrapper warps each published plane of length W·H with the same nearest map into a COPY (planes of any other size pass through untouched, none exist today). Forms that null their plane fields after publishing are unaffected.
- **Skip-when-empty:** `mods.AnyGeo` false ⇒ no clone, no loop, no wrapper — the default path is untouched code.
