## Description

**Found by T-0293 (A22 fifth pass) while walking every height profile by eye. Extends T-0278, which root-caused the same engine gap for the Steps DIAL and correctly greyed it; the PROFILE OPTION itself was never checked.**

**Measured, layer `normalKind = Profile` (the one setting under which a single-layer height stage can reach a pixel):**

1. **Stepped is pixel-identical to Flat, always.** 3 shapes (Rect, Ellipse, Star) x 3 Raises (4, 16, 48) x 4 Step counts (2, 4, 16, 32) = 36 comparisons, **0 of 4096 changed pixels every time**. Confirmed again at Raise 8 and 24 against a no-height-stage control.
2. **Flat and Stepped are also identical to having NO height stage at all**, at Raise 4, 8, 24 and 48: 0 of 4096. Dome/Round/Taper/Pyramid change 1890-2304 px at the same settings.
3. **Linear is intermittent**: identical to no-height at Raise 1-6 and 13-25, and 2304 px (the whole shape) at 7-12 and 26-64; at Raise 24 it is identical at Angle 45 and 2304 px at Angle 0/10/30/60/80/90. So Linear does respond over most of both ranges — it is not dead — but it flips as a whole rather than shading gradually, which is worth an engine eye.
4. All six BEVELS render distinctly on a Dome profile, Stepped bevel included (visible micro-terraces) — the bevel catalogue is fine. By-eye contact sheet: `workspace/T-0293/shots/a22-height-sheet.png` (row 1 = the seven profiles, row 2 = the six bevels).

**Cause** is the one T-0278 measured: `ShaperHeight.cs` `ExtrusionDerivative` returns 0 for Stepped (with Flat and Linear), so the shading normal is Flat's at every sample, and nothing gives a terrace riser a wall normal.

**Done in T-0293:** the Profile radio's tooltip no longer claims that every profile but Flat climbs differently — it now names Stepped as painting exactly what Flat paints and points at the same engine gap the Steps dial already names. That is honesty, not a fix.

**Open for the owner:** whether to build riser normals for a stepped profile (new rendering capability, which RULES.md #6 forbids this programme from adding), or to retire the Stepped extrusion technique from the picker (the enum is append-only, so it would be hidden rather than removed), or to leave it declared as it now is.
