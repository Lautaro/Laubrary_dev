## Description

Found 2026-09-29 while building the ZPOC player proof from a clean worktree of HEAD. Nothing was committed or changed in the live project to work around it; the worktree got local, uncommitted fixes only.

1. **Envelope fields.** `KlipWaveformTK` and `AudioSpectrumView` use `ZUIEnvelopeRuntime.dataXMin` / `dataXMax` (committed since T-0468, bede59e4). Those two fields exist only in an UNCOMMITTED 3-line change to `Zui/Scripts/Editor/ZUIEnvelope.cs` in the live project. The coordinator marked that file as not the agent's to commit, so it is left for the owner. Committing those 3 lines fixes the editor compile.
2. **Framework Trial.** `Assets/Framework Trial/` has editor scripts that are committed, but their Editor-only assembly definition (FrameworkTrial.Editor.asmdef) is not. A player build from a clean checkout fails to compile them.
3. **Plugins.** `Assets/Plugins/` is gitignored as a whole (Shapes, TextMesh Pro, others), so a clean checkout lacks the Shapes library that `LazorRenderer` uses. This is probably deliberate (third-party assets), but anyone cloning the branch needs them from elsewhere.

**Owner decision needed:** commit 1 and 2, or say how clean checkouts are meant to work.
