## Description

Gives a spawned pyre (or each pyre in a pool, from T-0034) real physical motion — velocity, gravity, drag, arc —
independent of the default "spawn and let it play in place" behaviour. `ChunkSpec`'s existing physics fields
already do this for debris chunks; this task applies the same physics to a pyre/blast instance instead of a
debris sprite.

Depends conceptually on T-0034 (Pyre Spawner) existing to move, but the physics logic itself should be written as
a reusable piece, not hard-coded into the spawner. Must work standalone otherwise (no layering/timeline/Mirage
required). See `CHUNKS_OVERHAUL_DESIGN.md` §"Standalone modules" #3.
