Two shared ZUI additions landed, both in the toolkit rather than inside DotGen, so every existing tool gains them at the same time.

Double-click a dial to put it back the way it shipped. Any slider drawn from an object's own fields - a Pyre modifier or form, a SpriteFx effect, a Chunks card, a Lathe module, a rule's parameters - now restores the value the author wrote into the type, and its hover text names that number instead of saying 'default'. It is one undo step and one re-render, exactly like letting go of a drag, so a dial pushed somewhere unrecoverable is one gesture from home. Sliders whose owner is a component or an asset (rather than authored data living inside one) are deliberately left alone.

DotGen's Generator Area will use it; Pyre has anchors too and can adopt it with one call.
