The toolkit can now draw a clock whose parts run at the same time, which is the shape a chunk recipe actually has. Until now a timebase could only be drawn as a chain - each stretch beginning where the last one ended - so a recipe reading "starts 0.15 s in" had its picture start somewhere else entirely, and any tool that needed the honest picture drew its own inside its own window. The new surface puts every part on one shared ruler at its own start and end, so two parts that overlap are drawn overlapping, with a name for each part down the left, marks for the recipe's cues, and one playhead the whole thing shares.

Three of its behaviours exist because the alternatives were measured and were worse: the ruler's length is set by the tool over every part including the switched-off ones (a length taken from what is visible lets switching one part off rescale the ruler and slide all the others sideways), a switched-off part keeps its row drawn faint (dropping the row changes the surface's height and moves the picture above it), and a number the playhead's readout would cover is dropped rather than printed underneath.

Two smaller things came with it. The older single-strip bar had the same collision rule but only made the covered number invisible - it was still there, still catching the pointer and still showing its own tooltip from under the readout; it is now removed properly. And the divider between a tool's control pane and its workspace can be put back: because its position is remembered forever, opening a window fresh was never a first run, so a pane dragged to an extreme stayed that way with no way home. Double-clicking the divider now restores the width the tool was designed at and forgets the saved one - fixed once, for every Laubrary tool, rather than as a button in each.
