T-0361 failures and findings: (1) at a 560 pt window the New row pushes Folder…, Create and Cancel off-screen (ZuiAudit: 3 off-screen) — the row must fit at every tool's minimum width (wrap the folder label to its own line or elide harder). (2) Any successful Create silently remembers its folder, so New offers that folder whatever asset is open — remember only an explicit Folder… choice; otherwise use the open asset's folder / the tool default as before. Check whether the same save-everything call exists elsewhere in the shared AssetKit base (Duplicate, Rename…) and fix it there too; list what you changed.
