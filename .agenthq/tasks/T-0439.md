## Description

A ZUI layout helper that places controls left to right and starts a new row only when the next one does not fit, deciding by the window's real width identically in every drawing pass. The chain editor's parameter drawing is rebuilt on it: sliders with the name inside, toggles whose face is the name, and choice strips without a separate label. Part of T-0437.

### 2026-09-27T16:46:00Z — agent — open -> done
Done. ZUI.WrapRow places controls left to right and starts a new row only when the next one does not fit. It decides from a width that is the same in Unity's layout pass and paint pass (the window's width, minus a margin measured on a paint pass), so the two passes never disagree about which row a control is on.
The chain editor draws every setting as a self-labelled control on it:
- sliders with the name, value and unit inside the track;
- toggles whose face is their name;
- choice strips without a separate label;
- icon strips.
A modulated slider gets a small '~' right after it, naming the modifier on hover. The old separate label column and the 56-point text tag are gone.
