## Description

**Owner's ask (his framing):** "These are suggestions. The task is not to change these specific things and then nothing else. These are examples on a UI philosophy you need to refactor every FX and Modifier with."

**The philosophy:** the chain editor is used wide, not tall. Horizontal space is cheap and vertical space is scarce, so controls spread sideways and wrap only when a row is full. There is no redundant text, and recurring shapes are built as reusable components.

**Owner's examples:** waveform shapes as icon buttons, not text; toggles whose own face is the label ('Retrigger'); Timing, Order and Interval side by side when there is room; effects with only a few sliders shown inline, with no expand step.

**Inventory (from the engine's own descriptions):** 16 effects. Nine have 1-3 settings (Gain, Normalize, Limiter, Low pass, High pass, Bit crush, Distortion, Fade); six have 4-5 (Compressor, Delay, Reverb, Flanger, Chorus, Phaser, Transient shaper); EQ has 9. On/off settings: Delay Ping-pong, Fade S-curve, Step Start random and Retrigger. Modifiers: LFO (7 settings, 3 choice strips), Step (6 plus bars), Envelope (2 plus curve), Random (Min/Max pair plus Bias).

**Rules applied everywhere:**
1. Every control carries its own label: a slider shows its name and value inside the track; a toggle's face is its name; a choice strip speaks through its options, with the setting's name on hover.
2. Controls flow left to right and wrap only when the row is full, at the window's real width.
3. An effect whose controls fit on its own row at the current width shows them there, with no expand step. One that does not fit expands, and its controls flow across the full width.
4. Shapes that recur are ZUI components, not one-off drawing.

**Sub-tasks:** T-0438 (ZUI icon choice and waveform icons), T-0439 (ZUI wrapping row layout and label-carrying controls), T-0440 (all 16 effects), T-0441 (all 4 modifiers). Done only when seen on screen at the owner's real window width, and at a narrower one.
