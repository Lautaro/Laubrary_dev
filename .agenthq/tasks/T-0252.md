## Description

Design discussed and agreed with Lautaro 2026-09-07. Original request in his words: "Floating Disc: there is a private Chunks for debris effect when the disc is hit. That debris should be sampled from the disc. When a chunk is connected to a zoe it should be able to take the zoe sprite as a 'parameter' and the particles or colors of the debris should be taken from the disc. The disc in the case its an in parameter should be shown somewhere and the palete or samples taken from it should also be shown... I want to be able to create a chunk that works without a zoe... the debris and particles spread by the chunk effect is way to small... it should be possible to set the size of the pixles in the debris to the pixel size configured for the project... i def want to be able to override that... the default should be that everything is made for the settings, in this case 320x200 pixels, fit on a steamdeck."

**Details:**
How to use this:
- On any Debris Scatter (in the Chunks window), a new 'Use project pixel scale' toggle (on by default) makes debris pixel size follow the project's Pixel Scale setting; switch it off to reveal an explicit override number.
- On a Zoe's Spawn Chunks / Pyre + Chunks reaction row (Zoetrope window), a new foldable 'Live sample preview' shows the frame standing in for the Zoe's current sprite, the colour palette it would sample, and (if the recipe has a Sampled-visual Debris Scatter) a few example cut pieces -- so you can see what will actually get sampled without entering Play mode.
- A Debris Scatter's own 'Sample source' field still works exactly as before for a standalone (non-Zoe) Chunks asset -- the live sampling only kicks in when a Zoe-event effect (Spawn Chunks / Pyre + Chunks) fires it.
- Floating Disc's private Hit debris asset (Assets/Zoetrope/Floating Disc.asset) was updated as the real test case: it now samples the disc's own current sprite (its authored sample source was empty before, so nothing was ever actually cut from it), and its piece size was bumped from 0.05-0.1 to 0.16-0.35 world units.
- Caveat: a clean before/after screenshot of debris mid-flight was not obtained (its lifetime is well under a second and screenshot round-trips kept missing the window); the sampling/sizing itself is verified instead by direct inspection of spawned chunks (sprite names, scales) plus a screenshot of the new Zoetrope-window preview -- both attached.
