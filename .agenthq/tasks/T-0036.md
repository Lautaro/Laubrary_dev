## Description

Splits a source sprite into a small number (2-6, not dozens) of large, recognizable pieces, each with its own
physical movement (reuse T-0035's physics where it makes sense). Distinct from the existing `SampledChunkSprites`
(which is tuned for many small, non-recognizable debris bits) — this is a NEW slicing mode aimed at "the pieces
still read as parts of the original thing," e.g. a spaceship Zoe's idle frame splitting into 3 recognizable hull
fragments.

Must work fully standalone (no layering/timeline/Mirage required). See `CHUNKS_OVERHAUL_DESIGN.md`
§"Standalone modules" #4.
