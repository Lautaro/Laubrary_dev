**Technical details:**
Method notes for whoever runs the sixth pass.

- unity-mcp `eval_file` takes top-level statements with fully-qualified types, NOT a class with usings; Coplay `execute_script` takes the class form. A probe written for one will not run under the other. workspace/T-0276/a12verify.cs is class-form and must go through Coplay with an explicit mode argument.
- Coplay's ScriptExecutor threw an unexplained NullReferenceException at IL offset 0x0e on a JObject-argument method while a sibling method in the same file accepted the same call shape; the capture helper was rewritten to take NO arguments and read its settings from EditorPrefs written by a unity-mcp eval immediately before the call. That shape is reliable: scratchpad/a22cap.cs.
- ZuiSection and ZuiBox have no public Title property. Read the private `_titleText` field. IsOpen is a public property on both.
- A synthesized click needs a laid-out target. After any Rebuild() the new elements have worldBound = (NaN, NaN) and a pointer click lands nowhere, silently. Either force a layout pass (panel.ValidateLayout() by reflection, wrapped as Layout() in a22-lib.txt) or split the gesture across two eval calls. A ZuiMenu popover in particular is only clickable in the call AFTER the one that opened it.
- ZUI menu items are plain VisualElements carrying `zui-menu__item`, driven by a Clickable, so they need PointerDown+PointerUp+Click; ZUI Buttons and ZuiToggleButtons respond to NavigationSubmitEvent.
- Direct field mutation on the window's bound document does not always invalidate the render cache, and a render sheet built that way silently shows the same picture six times. Build render fixtures on a detached ScriptableObject.CreateInstance<ShaperDocument>() (the pattern workspace/T-0284/mask-three-layer-probe.cs already uses) and drive the WINDOW only through its real controls.
- Temporal sampling at an interval near a multiple of the loop period makes a running transport look stalled and a stalled one look like it is stepping backwards. Sample at a deliberately non-commensurate interval before claiming playback works.
- The archived overflow probe is Y-only. Run a22-hov.cs too.
