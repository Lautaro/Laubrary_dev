## Description

Replace 'point order = time' path editing on the animatable 2D pad. Set the transport to a frame, then set a position on the pad: that defines a key at that frame only. A frame with no key shows a ghost where the value actually is (interpolated between neighbouring keys). The pad shows markers only for keyed frames, each labelled with its frame number. Keys stored as a fraction of the animation length so a frame-count change keeps them proportional; existing assets must keep playing identically.

DIVERGENCE NOTE: every commit in this programme is prefixed 'Pyre (pad/symmetry):'. Canonical Pyre moves forward independently of the unmerged Primitive3D work in D:/UNITY/Bakery; whoever does the Pyre+3D-shapes merge must grep for that prefix first.

### 2026-09-30T15:17:34Z — agent — open -> done
Animated 2D pad positions are now keyed at frames. Set the transport to a frame and click or drag in the pad to place the value on that frame; only keyed frames show a numbered dot; an unkeyed frame shows a hollow ghost ring where the value actually is on that frame. Pressing a key jumps the transport to it; right-click deletes one key. Keys are stored as a fraction of the animation (the scheme every animated Pyre value already uses), so frame-count changes keep them proportional and old assets play unchanged with no conversion. Wired into particle Offset, Crescent Mask centre and Transform Offset; the swarm Path stays a progress path.

[[attach:20260930T151734Z_keyed-pad-ghost.png]]
**Details:**
Laubrary Dev commit db8ec301. Commits are prefixed 'Pyre (pad/symmetry):' so the eventual Pyre + 3D-shapes merge can find them.
**Technical details:**
Measured: keys insert in time order, the ghost equals the runtime evaluation ((-6,3.2) on frame 3), a moved key keeps its time, same key maps to frame 11 of 32 after a 16-to-32 change. Driven with synthetic pointer events in a live window: click on an unkeyed frame adds a key there, second click moves it, Undo reverts it, pressing a key seeks the transport, right-click deletes one key. Seen by eye: keyed markers + ghost ring + 'Frame 3: ghost' status. Not verified: a human's real mouse; the Crescent Mask and Transform Offset pads were not opened (same code path).
