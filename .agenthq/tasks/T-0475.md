### 2026-09-28T13:48:24Z — agent — in_progress -> done
Data + handler, committed 66587a6e / 5bee6529.
Decision: a Looper is a SETTING ON THE KLIP (Klip.loop: enabled + crossmixMin/Max seconds), shown as a Looper in the editors, not a separate zound kind. Why: everything a Looper needs (audio, trim = loop points, chain, speed/pitch/volume ranges, editor, save format) is already the Klip's, and as a Klip it can be an entry in a Zequence of any mode (parallel, round robin, randomizer, playlist), which is how 'not mutually exclusive' holds.
Fixed-or-range stored like volume/pitch: equal ends = fixed.
Handler: a Looper's duration is infinite; stop goes through the normal kill path; rendered-file fallback sets audioSource.loop (plain loop, no crossmix) and the pool resets it on return.
Browser (old and new): clicking a playing Looper stops it rather than stacking another endless copy (one shared helper for all four click sites). Known limit: a Zequence CONTAINING a Looper still plays another copy on click; Stop all ends it.
Monitor (old and new): a Looper shows '12.3s - looping' instead of an infinite length.
