## Description

### What the owner sees

The analyser embedded in the sound editor animates too slowly, and sometimes not at all. His own guess is that it does
not animate unless the window has focus, and he notes that this is a familiar class of problem in editor tooling but that
something else in this project already gets it right — so there is a working pattern here to copy rather than invent.

### He is right, and both patterns are already in the codebase

The standalone analyser window keeps a subscription to the editor's own update tick and asks for a redraw from there,
once per tick, whether or not it has focus. That is the correct pattern, and it is the one the owner remembers working.

The analyser embedded in the sound editor does not do that. It asks for a redraw **from inside its own drawing code** —
the window draws itself, notices something is moving, and requests another draw. That only keeps going for as long as the
window is being drawn in the first place, which is the thing in question. An editor window that does not have focus is
drawn rarely and at the editor's convenience, so a redraw requested from inside a draw inherits exactly the rate it was
trying to escape. Hence: slow, uneven, and sometimes stopped altogether — and faster the moment the mouse is over it,
which is why it looks intermittent rather than simply broken.

### The fix

Give the sound editor the same update-tick subscription the standalone analyser window has, so a redraw is requested from
outside the drawing rather than from inside it. Requested only while something is actually moving, which both windows
already know, so an idle editor still costs nothing.

### Relationship to the other reports

This is very likely also the cause of the modulator-at-10-Hz report (T-0420 item 4): a display redrawn at an uneven and
sometimes very low rate cannot show a shape that repeats ten times a second, and what it shows instead is a different
shape every time — which is precisely what "the shape seems to change in itself" looks like. Tracked separately anyway,
because "the shape is wrong" and "the picture is stale" are different claims and only one of them has been demonstrated.
