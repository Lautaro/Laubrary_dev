## Description

THE SEVEN RULES
R1 ordering - mode on the member; children are a sequence not a set; fold order is immutable (no stage may reorder, including any optimiser); bottom of list = base, top applied last, matching the layer stack; first member folds against an empty accumulator; leading non-Add is UI-flagged, not seeded. Three modes (Add/Subtract/Intersect) + a width dial, not four. Intersect exists in neither tool.
R2 transform - 3D Shaper's block verbatim (translate/rotate/scale/skew/origin), 2D affine, T.P.R.S.K.P-inv, applied by INVERSE point-chaining (only the sample point travels down). Required by B9's block-of-canvas contract; forward-transform would cost a buffer + resample per node. Pyre's pitch/yaw explicitly excluded (they bake a perspective scalar; that is B7's). Origin as an authored field is the structural fix for the warp-pivots-at-top-right bug class. Distances are rescaled into CANVAS PIXELS on the way up by minStretch(M) = smallest singular value, after which B7's bound composes UNCHANGED. Singular linear part -> publishes empty + flagged.
R3 clock - a fill runs on the clock of the node it is attached to; combined with C4 that makes the bag's clock the default with no special case. A node's clock = parent's clock remapped through its own window (time composes like space). Pyre's startFrame/endFrame conflates remap with gating; split, adding a repeat mode (clamp/loop/ping-pong). Age travels in a plane with coverage, not derived from the clock. Named-quantity combination rule added (coverage-weighted average for continuous, strongest-wins for identifiers, subtracted members deposit nothing).
R4 swarm - yes, one contribution, which forces the real rule: a swarm resolves into a COVERAGE FIELD before publishing, never into pixels. Today's default (coalesce Off, every form) composites Over into a Color32 buffer per instance - unusable in a bag because a later Subtract cannot act on alpha-composited bytes. Not the same as Fuse (metaball sum + iso-threshold, different look, stays a separate choice). Bags may swarm; counts multiply along the path and the product is shown on the node. Simulation members greyed from the generic wrapper (C7's ~200x). Swarming replicates the SHAPE stage only - fill/border run once on the node's clock over the resolved plane.
R5 mask - drop MatteRole entirely. Every node publishes coverage; coverage IS a mask; the reference lives on the CONSUMER. That inversion kills all three of the concrete breakages at once (pointer-fetched-before-render, one shared mutable channel, PyreLayerKey excluding clip/luma). DAG, cycles refused at edit time. Visibility independent of being-read. Coverage refs depend on the source's shape stage; luminance refs on its full resolve - different dependency depths, deliberately. Fold order vs resolve order distinguished explicitly. Largest departure; no owner ruling exists; cheaper fallback (keep the enum, permit a combined Draw+Write role) is written out inline.
R6 softness - two knobs, from 3D Shaper, fixed twice. Formula is smoothMinShaped(a,b,k,n) = min(a,b) - h^n*k/(2n), h = max(k-|a-b|,0)/k, n = 8^sharpness. Width authored in PIXELS (Shaper scales k by the member's own shape dims, so equal viscosity gives different fillets at different sizes). Soft is a property of the seam, never the amount - Shaper's subtractSoft reads viscosity twice (also via sin(strength*pi)) so a full-depth soft cut is unaskable; that overload is not inherited. Combining happens on SIGNED DISTANCE, not coverage (blending coverage gives a cross-fade, not a fillet). Coverage-only domain declared for fog generators (sims, fire, Tapestry) per C3 - hard modes only, width greyed with reason; domain conversion is one-way and must be surfaced.
R7 cost - the task's premise is false today: rasters are bbox-bounded. A node is a BOUNDED pass, which needs a SUPPORT EXTENT declared per primitive - a second number, NOT derivable from B7's bound (a ratio carries no spatial information). Bag box folds in member order (Add unions, Intersect intersects, Subtract leaves unchanged), dilated by blend width. Four cliff multipliers named (canvas area, node count, swarm product, simulation members) plus a fifth to not inherit (geometry modifiers turning bounded rasters into per-particle full-canvas scans). Shown budget with named over-budget node + visible degradation, not a hard cap. Time-invariance propagates along ALL dependency edges incl. mask refs, not just parentage. One evaluation path for preview and bake (today none of the three caches is used at bake). Parallel axis is the canvas block, not the job.
