**Design decisions (logged, not asked):**
- **Engine = `JetProgram` (stages as virtual methods) + `JetSettings` (data, non-sealed).** The base program runs `Warp → Root → Emit → Rings → Sparks` then `JetShade`; every stage is a virtual method on a stateless program object (all scratch lives in a per-form `JetScratch`, so one shared program instance is thread-safe). A fork subclasses `JetSettings` for its data and `JetProgram` for its code: the radial fork overrides `Warp` (polar) / `BuildSlots` (stratified + permuted angles, bias, lobes) / `Emit` (swirl, spin) / `Root` (ring of lumps) / `Rings` (flat); the explosive fork additionally overrides `Frame` to insert flash / chunks / gobs / dust and `Shade`'s alpha for `opaq`. Helpers the forks need but the base does not use ship now, tested: `JetProgram.LeadRank` (rank-based `lead` via a stable argsort), `JetProgram.StratifiedPermuted` (numpy's `(i+0.5)/n` + jitter + `permutation`, bit-exact).
- **One program, five presets → `variant` + one `JetSettings` box per variant** (the Torch pattern): the five draws differ only by values (components switch on by value: root_r > 0, ring_n > 0, sparks > 0, soot > 0, pulse / sweep / shock / shed). **Default variant = `gout`** (#002): MANIFEST calls it "the classic … the draw that carries the territory … the flagship"; `lance` is #001 only by the calm-to-violent listing order.
- **Units:** the program runs in the draw's SOURCE px frame (w × h from the contract), sampled through u = (Size × canvas W) / w; px dials (r0, root_r, spark_r, ring_r0, warp0 / warp1 / warp_cell) stay in source px, `reach` / `buoy` / `grav` in canvas WIDTHS of that frame exactly as the contract says. The field is scale-invariant (blob kernels are normalised by their radius), so the fitted `lo` / `hi` hold at any canvas size. Shared dials are canvas fractions: Anchor X / Y (where the nozzle sits; Y from the TOP, the contract's own convention), Size, Swarm Size. The field is evaluated only inside the draw's own frame rect (what the source rendered; bounds the swarm's cost — the Torch rule). No supersampling: the source has none (1× grid, soft alpha from the field); point-sampled at u ≠ 1.
- **Fitted `lo` / `hi` / `curve` = frozen dials** (the contract's `fitted: true` values per draw), tooltips flag the fit and its targets. NOT `PlusClipStats`: the fitter (`_scratch/tune2.py`) solves against two style targets per draw with a damped alternation — porting the solver would make a dial drag re-fit the exposure, which is not what a user turning `strength` expects, and the frozen values are exactly what the contract's planes hold.
- **RNG exact:** `PlusNumpyRng` for the slot table (`seed·7919 + 13`), the sparks (`seed·104729 + 77`) and every noise lattice (`default_rng(seed·1000 + k).uniform(−1, 1, (pw, pv, pu))` as float32, C order). Swarm instances salt the seed by index × 104729 (the Torch rule). Seeds wrap to uint32 — exact for the contract's seeds (11 … 71), still deterministic for any spec seed.
- **LUT exactly as `flame3/lut.build_lut`:** 1024 entries, linear interpolation of the LINEARISED stops at np.linspace positions, re-encoded, rounded ONCE to uint8 sRGB, then decoded back to linear for the blend (the source quantises through uint8 before blending — a LUT straight from `PlusShade.BakeLut` would differ by a last bit). Alpha ceiling never goes through the transfer function. Soot = the second whole ramp crossfaded by `smoothstep((T/(H+1e-6) − soot_lo)/(soot_hi − soot_lo))` in linear light (whip's second ramp is HEAT, crossfaded the same way). `steps` quantises t (floor), never the alpha. Despeckle (alpha < 70, < 2 lit 4-neighbours) on the canvas after the write. Ramps ship as `PlusRampPresets.JetTorch / JetEmber (= Ember) / JetDirty(+Soot) / JetGold(+Heat) / JetWyrm` + `Jet(name)` / `JetSecondary(name)` / `JetSootWindow(name)`.
- **Loop:** phase = frame / frameCount (the source's `f / frames`), exact by construction (ku / kv snapped to whole lattice periods per axis, integer pulse / sweep counts).
- **Swarm:** off = one jet at Anchor aimed by the box's `aim`; on = one jet per instance rooted at the particle, rotated by its `orientDeg` (y-up CCW → the source's y-down frame), scaled by Swarm Size × sizeMul, amplitude × brightMul; heats and tints SUM.
