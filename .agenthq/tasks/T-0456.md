The new UI's look is a faithful COPY baked into USS (colours, gradients, sizes, shapes), not read from the Zounds style sheet at run time; and the controls are genuine UI Toolkit, with no IMGUI anywhere in the port. Missing primitives become real UI Toolkit additions to ZUI. The one-source-of-truth benefit is given up deliberately.
- D2: "EVERYTHING! Verify against the old version." Klip window, Zequence window and every main-window tab; each piece verified side by side before it counts as done.
- D3: delegated back: a temporary 'UITK' button in each old window opens its twin on the same sound; removed when the old window retires.
HOW D1 IS APPLIED (stated so it can be corrected):
- Controls are VisualElements styled by USS. USS has no gradient fill, so the sheet's gradient fills are baked once into small textures used as USS background images with 9-slice edges; that is ordinary USS, not custom drawing.
- Graphics that are data, not controls (spectrum bars, modulation lanes, waveform, curves), are drawn with UI Toolkit's own vector API (generateVisualContent / Painter2D), which is UI Toolkit's native way to plot. Where an old widget is a control (e.g. the EQ band sliders, the Step bars), it becomes elements.
- Values are copied from the old visuals by reading the Zounds sheet's definitions ONCE into the USS and textures, then checked against screenshots of the old windows.
ORDER: harness (T-0460) and the foundation gallery first, then Klip window, Zequence window, main-window tabs.
