**Details:**
Editor/Zoetrope/ZoetropeWindows.cs: BuildChunksRefRow's MiniRadio callback now calls a new MakeChunksPublic(prop, owner, current, label) when Public is clicked on a private row (previously that branch just called Rebuild()). MakeChunksPublic creates a new ChunkSpec asset under Assets/Chunks (the same default folder ChunkWindow already uses for this library), copies the embedded recipe's tuning into it via EditorUtility.CopySerialized BEFORE removing anything (so the data has a second, permanent, independent home before the embedded copy is ever touched), re-points the Zoe's field at the new asset through the existing Commit/ApplyModifiedProperties path, then removes the now-orphaned embedded sub-asset (AssetDatabase.RemoveObjectFromAsset + DestroyImmediate) and logs the created path via Debug.Log. Naming: strips a trailing ' (Private)' suffix if present, else reuses the embedded name, then GenerateUniqueAssetPath so it never collides with an existing library asset.

Undo: everything between Undo.GetCurrentGroup()/SetCurrentGroupName("Make Chunks Public") and Undo.CollapseUndoOperations(group) is folded into one group, so Ctrl+Z reads as a single step in Edit > Undo History - mirroring MakeChunksPrivate's own one-undo contract. One caveat, called out explicitly: the final sub-asset-removal step is not itself perfectly Undo-reversible, because Unity's Undo system does not track AssetDatabase-level object removal (the same limitation this codebase already accepts for AssetKit's own asset Delete, gated behind a confirm dialog rather than relying on Ctrl+Z). That is why the copy into the new public asset happens strictly before the removal - even in the worst case where Ctrl+Z does not perfectly restore the embedded copy, no authored data is actually lost, because it already exists as the new public asset.

The owner asset (the Zoe being edited) is only ever touched to drop its own embedded sub-asset via the removal call above - never renamed, no other field rewritten. CHANGELOG.md got a T-0364 (J5) entry under [Unreleased].
