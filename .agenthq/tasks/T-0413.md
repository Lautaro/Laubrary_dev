## Description

### What

Playback no longer renders a file: the chain is applied as the sound plays. The duplicate authoring surface is gone and nothing is written automatically, which is the file-count and complexity reduction that was asked for.

Bouncing a sound to a file was left in as something you ASK for rather than something that happens to you, because it is a working feature with real uses (handing a finished sound to someone, or to a tool that wants a file).

### The decision

Whether to remove it entirely. Keeping it costs a menu action and the code behind it; removing it means one less way to produce a stale file that looks authoritative.

Flagged to the owner; no action until they say.
