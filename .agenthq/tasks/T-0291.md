## Description

Found by T-0288 while driving sliders with synthesized pointer events. Narrow, but it is an unguarded path in a control every Laubrary tool uses.

**What happens.** `ZuiMicroSlider.ValueFromX` (`Zui/Toolkit/ZuiMicroSlider.cs:151-155`) is `Mathf.Lerp(_min, _max, Mathf.Clamp01(localX / Mathf.Max(1f, contentRect.width)))`. Before an element's first layout pass `contentRect.width` is **NaN**; `Mathf.Max(1f, NaN)` returns NaN (its comparison is false), `Clamp01(NaN)` returns NaN (both its comparisons are false), and `Lerp` returns NaN. The value is then handed to the caller's own callback with no guard.

**Measured consequence** on the transport: the Frame scrubber's callback is `currentFrame = Mathf.RoundToInt(v)`, and `Mathf.RoundToInt(NaN)` is **-2147483648**. Read back live: `playing=False frame=-2147483648`, with the window still running. `FillTransport` clamps on its next rebuild, so it self-heals rather than corrupting the document -- but `previewStripTile` took NaN the same way and drove the filmstrip's height to NaN until it was reset by hand.

**How it is reached.** Any press that lands on a slider in the same layout pass in which its pane was rebuilt. A physical mouse cannot normally do that (a human clicks at least a frame later), which is why this is filed rather than fixed -- but a scheduled rebuild plus an in-flight pointer is not impossible, and the guard is two lines.

Suggested shape: in `ValueFromX`, `float w = contentRect.width; if (float.IsNaN(w) || w < 1f) w = 1f;` and return `_value` unchanged when `localX` is NaN. Shared control, so it wants the usual cross-host check.
