## Description

Kiln's Tapestry Shape emits signed per-pixel height fields with the bevel profile already authored in (smooth/linear/chamfer/step plus width) - a colour return is rejected outright - so it is exactly the height source the lighting stage wants. Kiln's Tapestry Surface emits seamless full-colour material; two of its three generators (steel, steel_clean) are measurably shape-independent and become fill generators, but plasma is NOT a fill - given a blank field it renders alpha 0 everywhere, its alpha IS its silhouette, so it is an emissive shape-coupled treatment. Port natively rather than exporting files, because an exported file cannot respond to a dial in real time and cannot animate. Three things must be added to make them fills: a time input (they have none), a palette-quantise step so output stays pixel art, and a shape-local-vs-world coordinate switch (the patterns are tile-anchored, so a moving sprite will appear to swim without it). 248 published height fields already exist - 245 at 256 square, three at 128 - but they are unnormalised float32 in the range -1.648 to +2.206, so shipping them as presets needs a per-field normalise or a height-scale dial. Note a Tapestry tool ALREADY EXISTS in Laubrary (Runtime/Tapestry, Editor/Tapestry) with a layer stack, blend modes, a tiled preview and PNG export - it keeps its job as the place surfaces are authored and browsed, and its blend modes are worth taking.

The authoritative design is the "Shaper - the design" tab of this group's planning document (also at D:\UNITY\Laubrary Dev\.agenthq\workspace\T-0098\SHAPER_THE_DESIGN.md). Read it before starting.
