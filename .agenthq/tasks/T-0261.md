## Description

Lautaro's own words (2026-09-07): "Absolutely never no Unity native curveField controls. Always use ONLY ZUI Envelopes. Go through all chunks and replace the curveFields."

This restates and hardens the project's existing standing rule (CLAUDE.md -> "UI rule -- ZUI for ALL UI"): no native IMGUI/UIElements controls where ZUI already provides an equivalent. For AnimationCurve specifically, ZUI's own toolkit currently has TWO competing helpers and Chunks is using the wrong one everywhere.
