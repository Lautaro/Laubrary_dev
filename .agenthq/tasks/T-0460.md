Built (commit e56e2410): ZoundsUitkCompare (Editor/Zounds/Uitk). Puts the old IMGUI window and its UI Toolkit twin at the same size, lets both redraw, captures each window's client area as Windows draws it (PrintWindow, works behind other windows; the windows must float, since docked ones share a host window), and writes label_old/_new/_pair/_diff.png and the share of pixels differing by more than 8/255, in %TEMP%/ZoundsUitkCompare. A second, 'strong' view (difference over 48/255) separates antialiasing from real differences.
LEARNED ON THE FIRST RUN: at this display's 225 % scale a control at a fractional device pixel (x=10 -> 22.5 px) is rounded to opposite sides by IMGUI and UI Toolkit, one device pixel apart; controls on whole pixels land exactly. This is placement, not drawing, and matters for how the real windows are laid out.
