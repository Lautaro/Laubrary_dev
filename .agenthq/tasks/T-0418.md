## What a fresh agent should pick up

**Nothing is half-finished.** Every task above is either complete, waiting on the owner, deferred by the owner, or
blocked on a stated precondition. There is no work left mid-edit and no uncommitted change of mine.

The natural next piece that needs nobody's input is **the precondition T-0412 is blocked on**: a way to know that every
playing sound has actually STOPPED, rather than merely been asked to. Stopping is currently a request that takes effect
at the start of a sound's next block, so asking every voice to stop and then freeing what they were reading is a race.
That barrier is worth building on its own merits, and it unblocks the memory saving behind it.

## Two things that will save the next agent a day each

**A compiled job declared in a script the editor compiles at runtime silently runs as ordinary managed code, and produces
identical numbers.** So "the results match" is exactly what a silent fallback looks like, and is not evidence of
anything. Anything that must genuinely be compiled belongs in the package assembly. There is a kept check that witnesses
this rather than assuming it.

**Verify by observation, not by reasoning — this branch has three separate occasions where careful reasoning was simply
wrong**, each caught only by measuring:

- A voice being ACCEPTED by the audio graph was taken as proof it was being RENDERED. It was not the same thing, and
  establishing the second needed real audio read back and checked.
- Delay and reverb were classified as "trust the movement" on the strength of them moving by tens of decibels. That
  movement turned out to be the measurement's own noise.
- Sliding an analysis window along a repeating signal was argued to be safe because the signal repeats. It is not, because
  the window fades its own edges, and the error showed up as a waveshaper — which has no memory and physically cannot
  vary over time — appearing to move by five and a half decibels.

## Checks worth running before believing anything

Under **Laubrary > Zounds > Checks** in the menu. They build what they test in memory and never add anything to the
library, because the owner authors in this project live. Numbers 12 and 13 cover the modulation work, 11 covers layout
stability, and the earlier ones cover the port itself.

## Deliberately not committed

Nothing of this work. Note that the `.agenthq` folder carries a large amount of unrelated churn from other projects in
this repository — hundreds of task files and attachments belonging to AssetKit, Chunks and others. **Do not commit those
by sweeping the folder**; stage the specific task files being changed. That mistake was made once here and had to be
undone.

The repository's working tree also carries unrelated modified and untracked files belonging to the owner, across Lazor,
the demos and ZUI. Those are not part of this work and were deliberately left alone.
