### Things that will save the next agent a day each

**The board's own file format.** Task files written by hand without a `## Description` section lose their body the moment the board edits them, and the board shows them as empty. Every Zounds task was converted on 2026-09-27; create tasks through the API (`POST /api/task/create`), not by writing files, and keep `counters.json` ahead of the highest task number.

**A compiled job declared in a script the editor compiles at runtime silently runs as ordinary managed code, and produces identical numbers.** "The results match" is exactly what a silent fallback looks like. Anything that must genuinely be compiled belongs in the package assembly.

**Verify by observation, not by reasoning.** Five recorded occasions on this branch where careful reasoning was wrong until measured: a voice being accepted was taken for a voice being rendered; delay and reverb movement that was the measurement's own noise; a sliding analysis window argued safe; a shared barrier counter that could not tell two sounds apart (T-0419); and (T-0426) an oscillator judged to be a five-cornered polygon at 10 Hz because it was sampled once per 1024-sample block. The engine actually updates modulators every 64 samples and is exact.

**A numeric check proves nothing about what is on screen.** T-0424 was reported done on numbers while the owner saw nothing. Look at the window. The Klip Editor can be captured regardless of focus (see the Handover Log of T-0423 for how this was done), and the owner may be editing in it live, so disturb it as little as possible and say so on the board when you do.

**Editor probe gotchas.** A probe that sleeps the main thread right after pressing Play sees nothing playing: the voice only starts once the main thread runs. Recompiling closes the analyser and collapses rows in the owner's open window.
