## Description

Step 8 of the build plan from `D:\UNITY\Laubrary Dev\ZOE_PALETTE_BUILD_PLAN.md` (task 8 — read that file and `D:\UNITY\Laubrary Dev\ZOE_PALETTE_TAKE.md` in full before starting). Depends on T-0093 and T-0095.

Plain-language: right now, if a gun needs its own muzzle flash or similar look, that look has to be authored onto every character that could ever hold that gun — doesn't scale, and drifts out of sync as soon as there's more than one character. This task lets a weapon (and/or a piece of ammo) carry its own small declared list of named looks, the same shape as a character's palette from T-0095, so a gun's flash belongs to the gun rather than every character that might hold it.

This is the first real consumer of both T-0093 (game code choosing which name to request on fire) and T-0095's default-plus-override effect capability — worked example to build toward: a gun's muzzle look has an ordinary default flash, with a named override that plays instead when a specific powerup is active (the owner's own "FlamethrowerPowerup" example from T-0089's question history).

Explicitly out of scope for this task (per the round 4 build plan): ammo counts and reloading, and whether override names get the same generated/regenerated/checked-list treatment that character state names get in T-0092 — that's an open decision, flag it rather than assuming an answer.
