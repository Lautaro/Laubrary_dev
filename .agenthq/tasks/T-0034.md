## Description

Spawns one PyrePlus blast, or picks randomly from a configured pool of blasts, at a point. Already exists in
embryonic form (`ChunkSpec.animationSource` / `IChunkAnimation`, `ZoetropePyre/SpawnPyreFx.cs`) — this task
formalizes it as a standalone, reusable piece rather than something only reachable through a full Chunks burst.

**Pyre is deprecated (2026-08-18) — target PyrePlus only.** `ZoetropePyre/SpawnPyreFx.cs` and `PyreChunksFx.cs`
still bridge to old Pyre, not PyrePlus — this task needs to resolve whether it builds a fresh PyrePlus bridge or
those get migrated first (open question carried from the design doc).

Must work fully standalone (no layering/timeline/Mirage required). See `CHUNKS_OVERHAUL_DESIGN.md`
§"Standalone modules" #2.
