# Presentation regression guard

Run the guard from the project root with `python Documentation/UISeparation/check_presentation.py`. It examines only the explicit migrated production sources listed in `presentation-exceptions.json`: ZUI source files changed from migration baseline `9eb3d9c`, plus the AssetKit window. Reference fixtures are deliberately outside its scope.

The guard finds selected inline presentation assignments: background and text colors, font fields, opacity, border and radius fields, margin and padding fields, and width or height fields. It also surfaces literal Unity `Color` construction and named color constants as hardcoded-color candidates. Each candidate is compared as an exact whitespace-normalized physical source line, with a count. A new candidate, a changed source line, a duplicated occurrence, or an exception whose source line has gone away fails the guard. This makes removal of an old exception visible instead of leaving an unused allow-list entry behind.

`presentation-exceptions.json` is the review record, not a file-level exemption. The current baseline records 75 occurrences. Every entry names one target path, the detected kind, the normalized source line, its expected multiplicity, an allowed category, and a concrete reason. The allowed categories are `dynamicgeometry`, `content`, `compatibility`, `state`, and `legacydebt`; caller contracts and pre-resolution stylesheet fallbacks are recorded as `compatibility`, while actual measured or value-derived placement is `dynamicgeometry`. Review a changed exception as part of the same change that introduces it; do not add broad file allowances.

The guard is intentionally syntactic. It does not decide whether a particular expression is semantic data, layout, or a cosmetic decision, and it cannot cover every UI Toolkit styling API or every painter call. Painter drawing remains a manual review concern; the literal color check only draws attention to common hardcoded-color forms. It does not replace Unity compilation or an in-editor visual check.

Run `python Documentation/UISeparation/check_presentation.py --self-test` to verify the guard itself. The self-test first records a dynamic width occurrence and expects it to pass, then appends a synthetic `backgroundColor = Color.red` source line and expects the guard to fail.
