## 1. What 3D Shaper was

**Purpose.** A standalone, dependency-free, local-first browser app (Python 3.12 `server.py` + one `public/index.html`, port 4310, `shaper3d://` URL handler) for building stylised "2.5D" pixel-art models by hand. Its own vocabulary (README § Using the app): a **model** is the finished picture, a stack of layers, each a **shape** wearing a **material**, with edges and an extrusion, optionally animated. A **shape** is a colourless silhouette that is itself a stack of layers fused by Add / Add soft / Subtract / Subtract soft into one 2D outline. A **material** is colour + behaviour (surface, reflection, emission, pattern). It was built to mirror an older "reference browser app" (`retro_scifi_flyer_lab_draft6-1.html`, attached to T-0018/T-0027/T-0030 on its board) that the owner had used as a POC.

**Core concepts / technique.** Per-cell **signed-distance-field rasteriser** with a **height map and z-buffer** (`renderModelGrid()`, `public/index.html:1392+`): each layer flattened to a height grid, one winning material per cell, normals inferred from neighbouring heights, Lambert+Fresnel shading. No mesh, no camera, fixed top-down orthographic view. Eight 2D primitives (rectangle, ellipse, diamond, triangle, hexagon, octagon, capsule, star) with width/height/skew/corner-rounding/pinch-bulge; 7 extrusion profiles + 6 bevel profiles (open registries); 7 material surface categories (matte/glossy/metallic/glass/gelatinous/plasma/emissive), 12 patterns, emission glow pass; **pixel-material edge ring** (2–128 cells, 360° orientation, reach + reach-position, arc-length spacing, per-cell material from the pool); occlusion-aware layer border (a buried layer's outline painted onto the occluder); project-global light rig with several placeable lights and real shadows (lights are movable — it is the *camera* that does not exist); per-model timeline with 49 keyframe-animatable parameters (linear/hold/smooth), incl. canvas width/height/render-resolution; persisted undo/redo (100 steps, byte-bounded); nested composite shapes (frozen snapshot copies, cap 4 levels / 512 pieces); shared reference-image backdrop; LAN/Tailscale token mode.

**What it could NOT do (load-bearing).** No export of any kind — no PNG, no sequence, no sprite sheet (C-shaper3d.md §1; PRODUCT_CONTRACT "Intentional v1 limits"; GUG §8 "Shaper cannot export anything"). Materials have no alpha/opacity field (TRANSPARENCY_GRADIENT_INVESTIGATION.md, research only). Kiln fill/edge porting (T-0014) research only. And, per SHAPER_THE_DESIGN B6: the reference app's palette-strip carried **per-slot height (protrusion)**; 3D Shaper "reimplemented the strip and dropped the height" — the feature the owner remembered lived in the reference, not the port.

**State reached.** 58 tasks on its board, 57 done, 1 cancelled (T-0020 probe). Roadmap T-0001..T-0012 (contract → scaffold → data model/undo → renderer → shape library → composition → materials/lighting → layer stack → extrusion/bevel → pixel edges → animation → QA) all done by 2026-08-27; GAP_ANALYSIS (T-0018) counted ~33 of ~35 requested capabilities implemented, 2 partial; Phase 2 (T-0027, 2026-08-29) collapsed six tabs into three editors (Model/Shapes/Materials) + Lighting/Animation/Backdrop popovers, one shape type, thumbnail shape picker, stale-server banner; then a tail of UX tasks T-0028..T-0058 (undo everywhere, drag-reorder, per-layer thumbnails, inset-depth control, fuse radios) through 2026-08-30. **Ideas explicitly chosen to carry into merged Shaper** (SHAPER_THE_DESIGN, T-0098):

## 2. The Shaper design decisions (SHAPER_THE_DESIGN.md / planning Shaper.json, T-0098 round 4, 2026-08-30)

**Lineage.** Four T-0098 documents: *GUG — Future of Pyre* (R1), *Shapes / Fills / Borders* (R2), *Where I Stand — the nine answers* (R3, the owner's nine rulings), then *Shaper — the design* (R4, "This is a decision"). R4 supersedes the earlier three "except where this one says otherwise". A Q1 addendum rewrote B7 (3D rotation) the same day.

**The layer/generator model (Part A, C1–C2).** A document = canvas size, frame count + rate, palette, **one light rig**, ordered layers; "It resolves to a sequence of frames, and those frames bake to a sprite sheet or an animation" (C1). A layer holds **exactly one generator** plus optional stages; three layer kinds distinguished only by what the generator produces: *shape layer* (shape generator → optional border stage, fill stage, effects), *composite layer* (composite generator → effects only, "may not be re-filled"), *adjustment layer* (effects only). Masking "unchanged in principle" — a layer contributes its silhouette to a shared channel (though T-0103 R5 later ruled "drop MatteRole entirely; every node publishes coverage; coverage IS a mask; the reference lives on the CONSUMER").

**The three kinds of stuff + escape hatch (B1).** A generator declares one of four outputs: **shape** (per-pixel coverage, soft and unbounded; optional height; optional named quantities heat/density/soot/depth/age/surface-direction; never colour), **fill** (albedo, optional height delta, optional veil that multiplies coverage but "can never overrule the shape's own edge"; declares Over or Add compositing), **border** (a strip *region* derived from a shape's coverage — inward/outward/straddling, animatable width — painted by an ordinary fill; an outward strip joins published coverage by default), and **composite** ("the escape hatch: it produces a finished picture directly… Its contract is one line — it must publish coverage, and it may publish nothing else"; loses fill choice, border stage, and any sheet-needing effect; must carry a declared *reason*: AuthoredData (permanent) or NotYetSplit (temporary, shown on the layer)).

**Shape tree (B2, C3).** A node is a primitive or a bag; a bag's children each carry a combine mode and local transform; "a bag is indistinguishable from a primitive" downstream. Nesting depth uncapped in data; UI shows one level with a breadcrumb. UI rule: "complexity that is not in use is not on screen. A bag with one child renders its editor as though it were that child." Two B7 consequences: every node's height is a fixed recipe from its own edge distance, and **every primitive declares a Lipschitz-style bound on how far it may claim its edge is** ("the single most expensive thing to retrofit anywhere else").

**Fills (B4, C4).** Nearest ancestor owning a fill paints the subtree; a child with its own fill wins inside its coverage; default bag owns the fill. Fill vocabulary table: position-in-shape, signed edge distance, height, coverage, age + instance, time, named quantities. A fill needing an unpublished quantity is "greyed out with the reason shown — not hidden, not silently inert." Fill kinds listed: Solid, Gradient (linear/radial/angular/by-edge-distance), Ramp by quantity, Texture, Animated texture, Procedural (noise/plasma/Tapestry), Indexed strip. **"Reflective, shiny, bevelled and lit are not fills"** — "A fill emits albedo… The document's light rig turns albedo plus height into the final pixel. Shine belongs to the lights, not to the paint." The existing library-wide fill abstraction (`ZuiFill`) "cannot be extended in place… The new fill contract is a new thing that lives in the new namespace; the old one keeps working for everyone else and is not touched."

**Tapestry (B5).** Tapestry Surface's two metals → fill generators; the plasma is *not* a fill (renders nothing on a flat field) → composite/effect; Tapestry Shape → height generators; 248 existing height fields ship as presets (need normalise or a height-scale dial); in-tool generators, not an external file tool; the existing Laubrary Tapestry tool "keeps its job as the place you author and browse surfaces" and its blend modes "are worth taking".

**3D rotation (B7, rewritten by Q1).** "The first version still resolves flat, and the general path is designed in from day one." Measured 7–11× cost per dot when tilted, 1× at straight-down. Three hard requirements: the resolve is specified as a general line query, surface direction is *published by the shape* never inferred by the lighting stage, every primitive declares its edge-distance bound. Plus "one deliberately tilted picture is rendered through the general path and kept as a test" (delivered in T-0109). One open design question: what "edge distance" means on an extruded side wall. Owner offer: one word makes tilt usable in v1.

**Silhouette vs Solids (B8).** Names adopted: tool = **Shaper**, 2D-derived extruded generator = **Silhouette**, lit 3D primitive family = **Solids**. They "cannot share a layer" but "must share lights" through one shading law; "consistent, not identical, and that limit is stated in the UI". Solids is "the named exception to 'Silhouette is the only way to make primitives'".

**Performance (B9) — promoted from optimisation to contract.** Requirement 1 dial-moves-preview-moves via per-node content-addressed caching; Requirement 2 animations cache per frame, background pre-bake, visible cached-frame indicator; Requirement 3 **Burst-shaped contract**: "A generator does not get asked 'what colour is pixel 4,7?' a hundred thousand times. It is handed a block of the canvas and fills in plain rows of numbers." Canvas budget measured: default 96×64 (~6k cells), cap 68k cells.

**Swarm (C7).** A modifier on every generator: generic wrapper (N instances, per-instance clocks/seeds/jitter) + native path; which one is in use is shown. Simulations must swarm as many seeds in one sim. Defect to fix during port: instances start on the shared clock.

**Effects (C8).** Universal, with three preconditions (sheets, padded buffers, the never-called picture-rect). Pre-composite vs post-composite stage "stays an explicit property, shown in the UI"; an earlier claim it could be collapsed "is withdrawn". One ordered list with honest greying, not four typed lists (reversing R2's "split into four lists").

**Explicitly ruled IN:** generators (kept and made precise); sub-shapes; borders on any node; one fill contract; Tapestry as fills/height; Z translation ("cheap, add it"); the composite escape hatch; polygon + star engine (B11); sweep + shell on every primitive (B12); caching + Burst-shaped buffers; cloning as a git worktree + second editor + new namespace (B10); one board, a Shaper group (B14); planning-doc inlining into briefs (B13, built).
